description: Implement and diagnose React and TypeScript interfaces in the task target; excludes native mobile and other UI frameworks.

Inspect package manifests, TypeScript settings, rendering mode and the actual state/router libraries first. Keep domain data ownership and framework boundaries consistent with the target project. Model input and UI states explicitly; inspect effect cleanup, closure dependencies, stable identity and asynchronous updates when diagnosing behavior.
Check keyboard/focus behavior, loading/error states, long content and the actual rendering path. Profile a demonstrated performance issue before changing memoization or introducing a new state abstraction. Read framework-version-specific primary documentation when behavior depends on SSR, hydration or compiler features. Deliver code and observable checks; refer major design decisions to Grok or Codex according to difficulty.
